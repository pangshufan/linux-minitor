服务器监控告警Agent 证书

签发 Agent 证书

为新的监控主机生成证书和连接配置。

接入配置

请使用目标主机能访问、且在 Server 证书中登记的 gRPC 地址。每台主机使用不同的主机 ID；为同一主机再次签发时，旧证书仍然有效。

此 Server 还要求连接 Token。请在目标主机设置 MONITOR_AUTH_TOKEN 或在 Agent 配置中补填 auth-token。

安装下载包

ZIP 内含 agent.json、agent.crt、agent.key 和 ca.crt。请只交付给目标主机，Server 不保留这次生成的私钥。

Windows：解压到 C:\ProgramData\Monitor，再用 Agent 安装包中的 PowerShell 脚本安装服务。
